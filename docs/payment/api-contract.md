# Payment Module — API Contract

## Base URL

All endpoints are under `/api/v1`.

All authenticated endpoints require a valid JWT access token in the `Authorization` header.

---

## Payment Plans

### `GET /api/v1/payments/plans`

Lists available subscription plans. Publicly accessible (no auth required) so the mobile app can display plans before login.

**Query Parameters:**

| Parameter | Type | Required | Description |
|---|---|---|---|
| `is_active` | `bool` | No | Filter by active plans (default: `true`) |

**Response: 200 OK**

```json
{
  "data": [
    {
      "id": "uuid",
      "name": "Basic",
      "period": "monthly",
      "amount": 9900,
      "currency": "ETB",
      "isActive": true

      "id": "uuid",
```

## Initiate Payment

### `POST /api/v1/payments/initiate`

Starts a new payment transaction. Generates a deterministic `tx_ref`, creates a Payment record, and calls Chapa to get a checkout URL.

**Authentication:** Required. Uses `AuthMiddleware` + `AccountStatusMiddleware`.

**Request:**

```json
{
  "planName": "Pro",
  "period": "monthly"
}
```

| Field | Type | Required | Description |
|---|---|---|---|
| `planName` | `string` | Yes | "Basic" or "Pro" |
| `period` | `string` | Yes | "monthly" or "yearly" |

**Response: 201 Created**

```json
{
  "data": {
    "txRef": "tx_abc123_Pro_monthly_20260510120000",
    "checkoutUrl": "https://api.chapa.co/v1/transaction/initialize/...",
    "amount": 19900,
    "currency": "ETB",
    "planName": "Pro",
    "period": "monthly",
    "expiresAt": "2026-05-10T12:30:00Z"
  }
}
```

| Field | Description |
|---|---|
| `txRef` | Deterministic reference generated by the backend |
| `checkoutUrl` | Chapa checkout URL — open in WebView/browser |
| `amount` | Amount in minor units (satcker) |
| `expiresAt` | Time after which the checkout URL is no longer valid |

**Errors:**

| Code | Description |
|---|---|
| 400 | Invalid plan name or period |
| 404 | Plan not found or inactive |
| 409 | Active subscription already exists for this account+period (to prevent duplicate payments) |
| 422 | Chapa initialization failed |

## Verify Payment

### `POST /api/v1/payments/verify`

Verifies the status of a payment by `txRef`. Calls Chapa's verify API and updates the Payment record.

**Authentication:** Required.

**Request:**

```json
{
  "txRef": "tx_abc123_Pro_monthly_20260510120000"
}
```

| Field | Type | Required | Description |
|---|---|---|---|
| `txRef` | `string` | Yes | The transaction reference |

**Response: 200 OK**

```json
{
  "data": {
    "txRef": "tx_abc123_Pro_monthly_20260510120000",
    "chapaRef": "AP634JFwEbxd",
    "status": "success",
    "amount": 19900,
    "currency": "ETB",
    "planName": "Pro",
    "planPeriod": "monthly",
    "paymentMethod": "telebirr",
    "verifiedAt": "2026-05-10T12:05:30Z"
  }
}
```

**Errors:**

| Code | Description |
|---|---|
| 404 | Payment not found |
| 422 | Chapa verification failed (network error, invalid response) |

## Subscription Status

### `GET /api/v1/me/subscription`

Returns the current account's active subscription, if any.

**Authentication:** Required.

**Response: 200 OK**

```json
{
  "data": {
    "id": "uuid",
    "planName": "Pro",
    "planPeriod": "monthly",
    "amount": 19900,
    "currency": "ETB",
    "status": "active",
    "currentPeriodStart": "2026-05-01T00:00:00Z",
    "currentPeriodEnd": "2026-05-31T23:59:59Z",
    "renewalCount": 2
  }
}
```

**Response: 200 OK (no subscription)**

```json
{
  "data": null
}
```

## Webhook Endpoint (Chapa → Backend)

### `POST /api/v1/webhooks/chapa`

Receives payment events from Chapa. This is a **public endpoint** (no auth middleware) authenticated via signature header.

**Authentication:** HMAC-SHA256 signature in `x-chapa-signature` header, verified against `CHAPA_WEBHOOK_SECRET`.

**Request Headers:**

| Header | Description |
|---|---|
| `x-chapa-signature` | HMAC-SHA256 of raw JSON body using webhook secret |

**Request Body (charge.success):**

```json
{
  "event": "charge.success",
  "first_name": "Bilen",
  "last_name": "Gizachew",
  "email": "bilen@example.com",
  "mobile": "251912345678",
  "currency": "ETB",
  "amount": "199.00",
  "charge": "5.97",
  "status": "success",
  "mode": "live",
  "reference": "AP634JFwEbxd",
  "created_at": "2026-05-10T12:05:00.000000Z",
  "updated_at": "2026-05-10T12:05:27.000000Z",
  "type": "API",
  "tx_ref": "tx_abc123_Pro_monthly_20260510120000",
  "payment_method": "telebirr",
  "customization": { "title": null, "description": null, "logo": null },
  "meta": null
}
```

**Request Body (charge.failed/cancelled):**

```json
{
  "event": "charge.failed/cancelled",
  "tx_ref": "tx_abc123_Pro_monthly_20260510120000",
  "status": "failed/cancelled",
  ...
}
```

**Response: 200 OK** (must return 200 to stop Chapa retries)

```json
{ "status": "ok" }
```

**Idempotency:** If the same webhook event is received again (duplicate), check if `Payment.status` is already terminal (`success`/`failed`) and return 200 without reprocessing.

**Webhook Event Types:**

| Event | Action |
|---|---|
| `charge.success` | Mark payment success, create/update subscription, emit notification |
| `charge.failed/cancelled` | Mark payment failed |
| `charge.refunded` | Mark payment refunded (future) |
| `charge.reversed` | Mark payment reversed (future) |

## Route Summary

| Method | Path | Auth | Purpose |
|---|---|---|---|
| GET | `/api/v1/payments/plans` | None | List purchasable plans |
| POST | `/api/v1/payments/initiate` | JWT + Account | Start a payment, get checkout URL |
| POST | `/api/v1/payments/verify` | JWT + Account | Verify payment status |
| GET | `/api/v1/me/subscription` | JWT + Account | Get current subscription |
| POST | `/api/v1/webhooks/chapa` | Signature | Chapa webhook receiver |
